# basilharawedding.com

Basil & Hara — Saturday 27 February 2027, Greek Orthodox Cathedral of Saints Constantine and Helene, Perth.

One self-contained page, served by GitHub Pages.

- `/` — the envelope landing (choose English or Ελληνικά)
- `/en` and `/el` — go straight to a language, no envelope
- `index.html` — the whole site (settings at the top of the `<script>`: `WEDDING_ISO`, `RSVP_ENDPOINT`, `RSVP_EMAIL`; `REMEMBER_VISITS` in the `<head>`)
- `CNAME` — custom domain for GitHub Pages
